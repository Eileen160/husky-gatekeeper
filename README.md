# Husky Gatekeeper

## 中文

Husky Gatekeeper 是一個 Chrome 擴充功能。當你在指定網站停留太久時，哈士奇會出現並覆蓋頁面，提醒你休息一下。

### 功能

- 可監看指定網站，例如 YouTube、Facebook、Instagram、Threads、TikTok、Reddit、X。
- 可切換「鎖定所有網站與分頁」模式。
- 只在分頁可見且正在使用時累計時間。
- 時間到後會顯示全螢幕哈士奇休息畫面。
- 哈士奇出現時會暫停頁面上的影片與聲音。
- 休息期間會阻止頁面捲動。
- 可用「讓哈士奇離開」提前關閉休息畫面。
- 安裝或更新後會嘗試套用到已開啟的分頁。

### 隱私

Husky Gatekeeper 不會蒐集、傳送、販售或分析任何瀏覽資料。外掛會使用分頁網址來判斷目前頁面是否需要被監看或鎖定，但所有設定與計時資料都只儲存在使用者本機的 Chrome storage。

### 手動安裝

1. 下載或解壓縮這個專案資料夾。
2. 打開 Chrome，前往 `chrome://extensions`。
3. 開啟右上角的「開發人員模式」。
4. 點選「載入未封裝項目」。
5. 選擇 `husky-gatekeeper` 資料夾。

### 使用方式

1. 點選 Chrome 工具列上的 Husky Gatekeeper 圖示。
2. 打開「啟用」開關。
3. 設定使用時間限制與休息時間。
4. 選擇要監看的網站，或開啟「Block every site」鎖定所有網站。
5. 按下「儲存」。

## English

Husky Gatekeeper is a Chrome extension that shows a full-screen husky break screen when you spend too long on selected websites.

### Features

- Watches selected websites such as YouTube, Facebook, Instagram, Threads, TikTok, Reddit, and X.
- Supports a strict "Block every site" mode for all websites and tabs.
- Tracks time only while the tab is visible and active.
- Shows a full-screen husky break screen when the time limit is reached.
- Pauses page video and audio while the husky is on duty.
- Blocks page scrolling during the break.
- Lets you dismiss the husky early with the "Let the husky leave" control.
- Attempts to apply itself to already-open tabs after install or update.

### Privacy

Husky Gatekeeper does not collect, transmit, sell, or analyze browsing data. The extension uses tab URLs only to decide whether a page should be watched or blocked. All settings and timer data are stored locally in Chrome storage.

### Manual Installation

1. Download or unzip this project folder.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the `husky-gatekeeper` folder.

### Usage

1. Click the Husky Gatekeeper icon in the Chrome toolbar.
2. Turn on the Enable switch.
3. Set the usage limit and break duration.
4. Choose the websites to watch, or turn on "Block every site" to cover all websites.
5. Click Save.
