# Husky Gatekeeper

A small Chrome extension that shows a full-screen husky break screen after you
spend too long on selected websites.

## Load in Chrome

1. Open `chrome://extensions`.
2. Turn on Developer mode.
3. Click Load unpacked.
4. Select this folder: `husky-gatekeeper`.

## Behavior

- Watches the domains listed in the popup.
- Counts only while the page is focused and visible.
- Pauses page video/audio when the husky appears.
- Blocks scrolling during the break.
- Lets you dismiss the husky from the popup if needed.

The husky artwork is original SVG/CSS in this project.
